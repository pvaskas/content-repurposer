# Mode: EXTRACT

Input: a long source of the user's own material — email thread, proposal,
meeting notes, an assistant conversation.

## Job
Mine it. Find the 2-3 postable insights hiding in work already done.

## Process
1. Scan for: opinions stated in passing, post-mortem moments, explanations
   that taught something, numbers/gaps, concede-then-push arguments
2. Present findings as a shortlist: one line per insight + suggested
   mode/style/platform for each
3. Draft only what the user selects (hand off to REFINE/DEVELOP/STORY as fits)

## Rules
- Confidential details stay out — anonymize aggressively, this is client
  material
- An insight must survive without its original context; if it needs the
  whole thread to make sense, skip it
- Quality over quantity: 2 strong finds beat 6 weak ones. Zero finds is
  a valid answer — say so rather than forcing it
