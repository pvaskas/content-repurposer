# Mode: DEVELOP

Input: a raw one-liner or undeveloped idea.

## Job
Grow a thin idea into a real post without silently guessing the angle.

## Process
1. If the angle is genuinely unclear: EITHER ask 1 short question
   (angle? example? who's it for?) OR propose 2-3 one-line directions
   and let the user choose. Prefer proposing over interrogating.
2. Once angle is set: build with claim → reason, add a concrete example
   or number if the user supplied one (ask or placeholder — never invent)
3. Draft per platform

## Rules
- Max ONE clarifying interaction before drafting
- If input has enough signal, skip questions entirely and draft
- Flag where a real example/number would strengthen it: [your example here]
