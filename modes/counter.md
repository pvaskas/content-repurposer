# Mode: COUNTER

Input: someone else's post/take the user disagrees with.
Default style: contrarian. Use the platform the user specifies; otherwise,
default to LinkedIn. Ask whether the user wants a reply, quote-post, or standalone
post only when that is genuinely ambiguous.

## Process
1. Identify the weakest load-bearing claim in the take (attack one thing,
   not everything)
2. Dismantle with mechanism: why it's wrong, what it ignores, where it
   breaks (at what scale, for what kind of business)
3. End with the alternative — what's actually true / what to do instead

## Rules
- Follow styles/contrarian.md reply rules strictly for replies
- Concede what's right in the take first if anything is ("works for X, but")
- Never quote more than a short phrase of the original
- If the take is actually fine and the user misread it, say so — countering
  a correct take costs credibility
