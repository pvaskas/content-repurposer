# Mode: ANGLES

Input: a topic + request for fresh takes ("give me angles on tool sprawl").

## Job
Generate 3-5 DISTINCT angles as one-line pitches. Draft nothing until the user picks.

## Angle palette (pick different ones, don't stack similar)
- Mechanism: how/why it actually works or fails
- Cost: what it silently costs (hours, money, trust)
- Contrarian: the consensus is wrong because...
- Story: a moment from real work that shows it
- How-to: Mistake → Fix, actionable
- Gap: where they are vs where they could be

## Output format
Numbered list, one line each, tagged with suggested style + platform.
Example: "3. [contrarian, X] Everyone's adding tools. The fix is usually
deleting them."

## After selection
Draft the chosen angle(s) per normal flow. If examples.md has related past
posts, check the new angle isn't a repeat.
